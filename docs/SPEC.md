# Frozen core: Day 29 Tracepath

Scope version 1. Assigned date 2026-11-14. Author Ajay Mekala.
Source: day-29-tracepath-prompt(1).md, current version 0.

Build one gateway and one worker connected by real HTTP, a Postgres receipt
ledger, bounded OTel export to a Collector, and an independent topology checker.
Actual CPU inference uses pinned BAAI/bge-small-en-v1.5 artifacts through
FastEmbed and ONNX Runtime. Search all 24 original CC0 operations notes with
dense cosine, lexical BM25 and reciprocal rank fusion. Return five documents.

Freeze 24 scenario lineages, two development and two reserved in each of six
families. Execute 24 reserved traced/untraced rows and 72 paired normal HTTP
requests. The primary invariant is business-output agreement. Trace coverage
and paired client overhead are separate descriptive outcomes.

The public Python API performs bounded lexical requests with scoped expiring
sessions, atomic persisted receipts, payload-bound replay and conflict handling.
Actual embedding remains in the recorded local experiment. Response-send
observations on the public API remain unavailable unless independently observed.

Four React/TypeScript views: Request, Trace, Coverage, Method. Use the specified
patch-panel palette, both themes and self-hosted Red Hat Display, Red Hat Text,
and Cascadia Code. Test 390, 768, 1440 pixels, keyboard and 200 percent zoom.

Mandatory acceptance includes real model execution, independent connection and
process readback, dropped spans and collector outage, retry identities, process
death after commit, privacy canary, 18-line checklist, clean rederivation and
40 meaningful commits. Incomplete gates remain not done. Stretch is excluded.

Portfolio observability experiment around a small retrieval service.
The corpus and fault cases are authored synthetic fixtures.
Actual CPU embedding, live lexical requests and recorded traces are separate.
Missing telemetry remains unknown. Results apply to the declared workload,
artifacts and environment, not production reliability or general RAG quality.
