# Tracepath operating rules

Build only the frozen Day 29 core in docs/SPEC.md. Preserve failed observations.
Business receipts and telemetry are independent evidence. Never claim missing
spans mean zero time. Never substitute a fixture for actual CPU inference.

Use only original synthetic text. No raw query, document, credential, connection
string, session token or baggage in exported attributes. Use dedicated databases.
No paid services, card entry, profile edits, messages or social posts.

Run pytest, the independent grader, evidence verification, and the web build.
Run real integration checks when dependencies are ready. A skipped check is not
a pass. Register changes to the study before reserved execution. Keep every
planned ID in reports. Do not import expected verdicts into runtime packages.

Use conventional commits authored by Ajay Mekala <mekalaajayk@gmail.com>.
No empty commits or history rewriting. Keep PROJECT_STATE.md and NEXT_SESSION.md
current. Do not publish a release until every mandatory gate is supported.

Human-facing prose is ASCII, without apostrophes or quotation marks. Code syntax,
source quotations, identifiers and third-party license text are exempt.
